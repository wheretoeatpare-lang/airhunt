Step 1

Create a free Duffel account

Go to app.duffel.com and click Sign up. Takes about 1 minute — no credit card needed.

Step 2

Create an access token

Inside the Duffel dashboard, go to Developers → Access tokens and click Create token.

Copy the token — it starts with duffel_test_... (test mode) or duffel_live_... (live mode). Start with test mode first.

Step 3

Paste your token into js/app.js

Open js/app.js and find the DUFFEL config near the top:

// js/app.js — near the top
const DUFFEL = {
  token: 'duffel_test_YOUR_TOKEN_HERE',  // ← paste here
};
Step 4

Push to GitHub → Cloudflare deploys automatically

git add js/app.js
git commit -m "Enable Duffel live flight booking"
git push origin main

Cloudflare Pages deploys in ~60 seconds.

Step 5

Test: search a flight and book!

Search any route — you'll see a ✓ Live price badge. Click Book now and fill in passenger details directly on your site. The booking is confirmed with the airline and a booking reference is returned — no redirect needed.

⚠️ In test mode, no real money is charged and no real tickets are issued. Switch to duffel_live_... tokens when you're ready for real bookings (requires Duffel approval for live access).

What works without a Duffel token?

Everything! Estimated prices are shown and the booking modal includes direct links to Google Flights, Kiwi.com, Skyscanner, and airline websites with your route pre-filled. Users can always book — they just go to an external site instead of staying on yours.
